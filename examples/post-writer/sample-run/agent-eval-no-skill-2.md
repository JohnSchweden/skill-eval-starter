Built a skill for my agent last month. I was sure it made my posts better.

This week I finally tested it, with and without the skill. The version without the skill scored higher.

My first reaction was to blame the skill. Then I checked the test itself. It was outdated. It was measuring against criteria I no longer cared about, so the scores didn't tell me anything about the skill.

Once I fixed the test, I had to admit I'd been judging the skill on a feeling, not on evidence. I'd never measured the posts before or after.

Lessons I'm taking away:

- Re-check your evals when your goals change. A stale test can be wrong in a convincing way.
- "I think it's better" is a hypothesis. Test it before you build on it.
- A bad result can still be useful. It sent me back to check my assumptions.
